# Student Management System

A web-based Student Management System built using Python, Flask, HTML, CSS, and SQLite. This project helps users manage student records through a simple and user-friendly interface.

## Features

- Add new student records
- View all student records
- Search students by name or email
- Edit existing student details
- Delete student records
- Store student information in an SQLite database
- Validate student marks between 0 and 100

## Technologies Used

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **Tools:** Visual Studio Code, Git, GitHub

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Pradeep12346788/student-management-system.git
cd student-management-system
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install Flask

```bash
python -m pip install flask
```

### 4. Run the application

```bash
python app.py
```

Open your browser and visit:

http://127.0.0.1:5000
